# Packet-Sniffer

#What was used?
To install a packet sniffer, you need three things: scapy library, python, and NPCAP. Scapy library uses the programming language python to allow users to sniff, decode packets, etc across networks. Python is the programming language used to create the packet tracer, and NPCAP is used to capture the packets.

#How to install the packet sniffer
First, I installed scapy library, python, and NPCAP and then I installed copilot. Afterwards, I had it write a piece of code for the packet sniffer, then I copied and pasted it on a notepad and changed the file extension from .txt to .py. After that, I opened up Powershell and ran it as an administrator and used the command copilot gave me.

#What the packet sniffer does
The packet sniffer went through my network and captured all the packets on there. It listed some devices that was on my network as well as IP Addresses.

#Safety
To be safe, it is wise not to share the packet capture with anyone because it contains sensitive information and I only captured packets on my network.

#Examples of running the packet sniffer
The one way to run it is listed above: place the code on a notepad, save it with the .py extension, and then use command prompt to capture the packets.
